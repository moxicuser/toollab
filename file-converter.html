Supported conversions and limitations

          

            XML, JSON, YAML, CSV, and TSV can be converted as structured data. Text, Markdown, HTML,
            and RTF can be exported into document and data formats. Modern Word files (.docx) can be
            converted to PDF, and text-based PDFs can be extracted into DOCX or text formats. PDF and
            DOCX conversion preserves readable text, not the original page layout, fonts, tables, or
            images. Scanned PDFs need OCR and are not read by this tool. Legacy binary Word files (.doc)
            are not supported.
          

          

            Images can be converted to PDF. Files are processed locally in the browser; conversion
            libraries load from public CDNs, so an internet connection is needed to open this page.
          

        


        

          
XML and data-format conversion

          

            XML files are parsed into a data structure before conversion to JSON, YAML, CSV, TSV, SQL,
            or other text outputs. Attributes are retained with an @_ prefix, repeated XML
            elements become arrays, and text mixed with child elements is stored as #text.
            These conventions keep values accessible, though converting between formats with different
            structures can change how nested data is represented.
          

        

      


      

        
Frequently asked questions

        

          

            
Can I convert a Word document to PDF?

            
Yes, for modern .docx files. The output keeps extracted text but does not reproduce complex document layout.

          

          

            
Can I convert PDF back to Word?

            
Text-based PDFs can be converted to .docx. Scans, layout, tables, and images are not reconstructed; scanned PDFs need OCR.

          

          

            
Which XML conversions are available?

            
Convert XML to JSON, YAML, CSV, TSV, SQL, text, and other supported formats. The reverse conversions are available where structured data can be represented.

          

          

            
Are my files uploaded?

            
No. File contents are processed in your browser. Conversion libraries are fetched from public CDNs when the page loads.
