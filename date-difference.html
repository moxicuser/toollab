How to use the date difference calculator

  1. Choose the first date.
  2. Choose the second date. It can be earlier or later than the first.
  3. Select Calculate difference to see the gap in days and weeks.
  4. Use Copy result to copy the summary for a document or message.

How the date difference is calculated

The calculator converts each calendar date to a UTC day value and subtracts the earlier date from the later one. Because it compares calendar days rather than elapsed hours, daylight-saving changes do not add or remove a day. The date gap counts the days after the first date up to and including the second date. The inclusive total adds one to count both endpoint dates, which is useful when counting a multi-day event or booking.

Days between = later date - earlier date

For example, the gap from June 1 to June 8 is 7 days. Counting both June 1 and June 8 gives an inclusive total of 8 calendar days.

When to use each result

Use “Days between” to measure elapsed calendar days, such as the time until a deadline. “Weeks and days” expresses the same gap in a form that is easier to scan. “Inclusive days” counts both selected dates and can help estimate a trip length or event schedule. This tool does not exclude weekends or public holidays.

Frequently asked questions

Does the order of the dates matter?

No. The calculator sorts the dates and reports the positive difference.

What does inclusive days mean?

It counts both the start date and end date, so it is one more than the elapsed day difference.

Are weekends included?

Yes. The result counts all calendar days. It does not remove weekends or holidays.

What if I choose the same date twice?

The elapsed difference is zero days, and the inclusive count is one calendar day.
