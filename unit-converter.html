How to use the unit converter

  1. Choose a measurement category.
  2. Enter the value you want to convert.
  3. Select the source and target units.
  4. Choose Convert, or swap the units to reverse the conversion.
  5. Copy the displayed result when you need to use it elsewhere.

How unit conversion works

For length, weight, volume, and speed, the converter first changes the input to a standard base unit, then changes that value into the selected output unit. This keeps conversions consistent across metric and customary measurements. Temperature uses separate formulas because Celsius, Fahrenheit, and Kelvin have different zero points as well as different scales.

Converted value = input value × source factor ÷ target factor

For example, a kilometer contains 1,000 meters and a mile contains 1,609.344 meters. Therefore, 1 kilometer is about 0.621371 miles. For temperature, 0°C is 32°F and 273.15 K.

Choosing the right units

Use length conversions for travel, construction, and object measurements; weight conversions for recipes and shipping; and volume conversions for liquids. Temperature conversions help compare weather or cooking instructions. Speed conversions are useful for comparing road speeds and pace. Results are rounded for display, while calculations use the full conversion factors in the browser.

Frequently asked questions

Which categories are supported?

The converter supports length, weight, temperature, volume, and speed.

Are US and Imperial units the same?

Not always. This tool labels US customary units explicitly where their values differ, such as US gallons.

How precise are the results?

The calculation uses standard conversion factors and displays up to eight significant digits.

Is my value sent anywhere?

No. Unit conversions are calculated locally in your browser.
