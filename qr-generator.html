How QR codes work

A QR code stores text that a camera or QR reader can scan. For a website, social profile, image, or document, the code stores a URL that opens the destination. For Wi-Fi, email, phone, and WhatsApp, it stores a formatted action that compatible devices can recognize. This generator builds the code in your browser and does not send the content you enter to ToolLab.

Using QR codes for images and documents

A QR code cannot practically contain a full image or document. First upload the file to a service that provides a share link, then paste that link into the Website or file link option. Set the file's access permissions so the people who scan the code can open it. The QR code stores the link, not a copy of the file, and the linked service controls access.

Before you share

Scan the downloaded image with your phone before printing or posting it. Check that links open the intended page and that shared files have the right access settings. Wi-Fi QR codes include the network name and, when required, its password; share those codes only with people you trust.

Frequently asked questions

Can I make a QR code for a PDF or image?

Yes. Paste a shareable URL for the file. The file must be hosted online and accessible to the people scanning it.

Can the QR code contain the whole file?

No. QR codes have limited capacity and are not a practical way to store full documents or images.

How do WhatsApp QR codes work?

They open a WhatsApp chat link for the number you enter. Include the country code and omit spaces or punctuation from the actual number.

Is my content uploaded?

No. The code is generated locally in your browser. The QR library is loaded from a public CDN.
